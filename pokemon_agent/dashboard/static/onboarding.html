Use a legally owned Pokemon ROM to start a local bot run. ROMs stay on this machine under the configured pokemon-agent data directory.

Before You Upload

This project does not provide, download, or distribute Pokemon ROMs. Upload only ROM files you legally own.

Compatible file extensions: .gb, .gbc, and .gba. Gold/Silver are currently the strongest autoplayer targets; Red/Blue have structured RAM support; Yellow still needs validation.
